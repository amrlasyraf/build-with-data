Local retail data project

A retail pipeline you can run and inspect.

Start with three CSV files. Pandas prepares Bronze, Silver, and Gold; DuckDB stores each layer for local queries. The core project ends at Gold. You can explore the other branches later if you want to.

How the work connects

Bronze, Silver, and Gold are the main data engineering path. Power BI and forecasting are separate activities you can try later.

Role Responsibility in this project
Data Engineer

Load Bronze, clean and join Silver, aggregate Gold, and inspect each result.
Data Analyst (optional)

Turn Gold metrics into a Power BI report that explains sales, category mix, channel performance, and estimated gross profit.
Data Scientist (optional)

Use Silver sales to guess next month's sales by category and channel, compare two methods against past months, and explain why the errors are too large for business use.

Questions this project asks

The current analysis is about sales and estimated gross profit. The forecasting experiment asks whether a model beats a seasonal baseline. Its high error is part of the result.

Current analytics question
How do sales and estimated gross profit change by month, product category, and sales channel?
Forecasting experiment
Given history up to this month, what gross sales might each category and channel produce next month?

Run it locally

Run the pipeline locally

  1. Install Python 3.11 or newer, VS Code, and its Python extension.
  2. Download and extract the repository, then open its folder in VS Code.
  3. Use the terminal once to create an environment and install the packages; select that interpreter in VS Code.
  4. Open bronze.py, silver.py, then gold.py. Click Run Python File in each one.
  5. Open support/viewer.py and click Run Python File to inspect each layer.

Forecasting experiment

Use Silver to estimate next month's sales by category and channel. Compare a simple last-year guess with a model; both have high error, so this is practice only.
